GreenByte-Bio
AI-Driven Sustainability Intelligence for Biotechnology & Life Sciences
> Measure • Understand • Reduce • Predict
> Making every Bio-Byte greener.
What it is
GreenByte-Bio is a client-side web prototype that makes the hidden digital and energy footprint of biotechnology and life-science research visible and actionable — covering genomics, bioinformatics, AI/ML drug discovery, cloud storage, high-performance computing, digital microscopy and research collaboration.
Built for Hackathon on Sustainable Bio-Innovation Ideas – Phase 2, "The Idea Nurturing and Startup Readiness Camp", organised by EXCELR in association with Acharya Nagarjuna University, Guntur, sponsored by RUSA 2.0, ANU (18–21 August 2026).
Key features
Interactive Bio-Lab Sustainability Assessment (4 preset scenarios: Genomics, AI Drug Discovery, Digital Microscopy, Cloud Research)
Bio-Lab Green Score (0–100) across 8 sustainability dimensions
Digital footprint breakdown chart (compute, GPU, storage, transfer, imaging)
AI Green Coach — dynamic, rule-based recommendations
What-If Simulator — current vs. greener workflow, with reduction %, savings, and annualised impact
Collective Impact slider (10 / 100 / 1,000 labs)
Judge Mode — a guided 10-slide presentation for rapid evaluation
Industry View — a CEO/partner-facing summary with a demo-request action
Fully responsive, accessible, and printable (Green Report via browser print)
Tech stack
Plain HTML5 / CSS3 / JavaScript (no build step), Chart.js for charts, Font Awesome for icons, Google Fonts (Space Grotesk, Inter, IBM Plex Mono). No backend and no external data collection — everything runs client-side in the browser.
Data transparency
All footprint, energy and Green Score figures are indicative estimates based on configurable, illustrative assumptions entered by the user. The prototype does not directly measure electricity consumption or actual carbon emissions.
Run locally
Just open `index.html` in a browser — no build step required.
Deploy to GitHub Pages
Create a new GitHub repository (see suggested name below) and push these files to the `main` branch.
In the repository, go to Settings → Pages.
Under Build and deployment, set Source to `Deploy from a branch`, branch `main`, folder `/ (root)`.
Save. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within a few minutes.
